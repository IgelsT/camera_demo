# Система видеонаблюдения из старых смартфонов

http://camera.imile.ru/

## 1. Приложения для Android.

- Работает с android 4.2
- Работает с камерой в фоне, при выключенном экране.
- Кодирует видео поток в h264, аппаратно с помощью MEdiaCodec
- Отправляет поток по rtmp
- Принимает сообщения с сервера для смены состояния. изменения настроек.

## 2. Web интерфейс для просмотра и управления.

- Просмотр изображения с камер, интерактивный дашборд
- Отправка сообщений устройствам для смены настроек/состояния
- JavaScript, Vue, Quasar

## 3. API у всех совместимость по форматам входящих и исходящих json

### 3.1 api_v1 чистый PHP

- Маршрутизация
- Валидация входящих json, мапинг в объекты
- Обрабтка ошибок
- QueryBuilder

### 3.2 api_v2 Laravel

- Использует ту же БД что и api_v1
- Реализует те же маршруты что и api_v1
- Формат входящих и исходящих json совместим с api_v1

## 4. БД MySql/Mariadb

- Есть Хранимые процедуры
- Схема БД в api_v2/database/migrations
